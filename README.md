# Instapro

MVP социальной сети для обмена фотографиями

## Первоначальная оценка

ХХХХ часов

## Фактически затраченное время

Суммарно, с учетом перечитывания конспектов и поиска дополнительной информации в сети - 12-14 часов

## Реализовано

- Общая лента постов (для авторизованных и неавторизованных пользователей)
- Лента постов конкретного пользователя (переход по клику на имя автора)
- Авторизация и регистрация (с загрузкой аватара)
- Добавление поста с текстом и фотографией (только для авторизованных)
- Лайки и дизлайки с обновлением счётчика без перезагрузки всей страницы
- Удаление собственных постов
- Сохранение авторизации после обновления страницы
- Русские относительные даты ("5 минут назад", "2 часа назад")
- Экранирование HTML-тегов в текстах (защита от XSS)
- Анимация лайка (увеличение сердечка при нажатии)
- Подсветка имени автора при наведении
- Адаптивная вёрстка (центрированная колонка, компактные картинки на мобильных)
- Кнопка "Удалить" только на своих постах
- Индикатор загрузки при переходе между страницами
- Сообщения об ошибках в формах
